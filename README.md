# Description
**TMR Calculator** est une application web développée avec React permettant de calculer le **Taux Moyen de Rentabilité (TMR)** d’un investissement. L’utilisateur peut saisir le capital engagé, la valeur résiduelle, la durée de l’investissement et les résultats nets annuels afin d’obtenir automatiquement le TMR, le niveau de rentabilité et différentes statistiques. L’application propose également des graphiques pour visualiser les résultats, le cumul des revenus et une estimation de la rentabilité future selon un taux de croissance choisi.
